# Avatar collection (24)

Twenty-four of the eighty generated portraits supplied as
`80_Comic_Graffiti_PopArt_Anime_Avatars.zip` (12 comic, 4 anime, 4 graffiti,
4 pop-art), resized from 512 px to 160 px to keep the app small. They are
generated artwork (no identifiable people). `src/profile/avatars.ts` lists them;
the id stored on a child profile is the file name without `.png`.
