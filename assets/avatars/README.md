# Avatar collection (80)

Supplied as `80_Comic_Graffiti_PopArt_Anime_Avatars.zip`: 50 comic (`comic_NN.png`),
10 graffiti/street (`graffiti_NN.png`), 10 pop-art (`popart_NN.png`) and 10 anime
(`anime_NN.png`). Each is a 512 x 512 PNG with a circular transparent edge. The zip's
note says they are resized crops from generated contact sheets, not native 1024 px
renders, so fine detail is limited. `CONTACT_SHEET.png` shows them all with their
file names.

They are **not yet wired into the app**: the profile avatar gallery will use them
once the collection is approved.
